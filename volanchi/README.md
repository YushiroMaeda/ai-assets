# ボランチくん チャットボット用アセット

在宅向け薬宅配システム「ボランチくん」のサポートチャットボット(Dify上で構築)で使用する画像ファイルを管理するディレクトリです。

## ディレクトリ構成

- `v1/manual/pages/` ... 基本操作ガイドのページ全体画像
- `v1/manual/elements/<章番号>_<章名>/` ... UI要素の切り出し画像
- `v1/feature/` ... 機能イメージ資料の画像

## バージョニング方針

マニュアル改訂時は `v2/` を新規作成。古いバージョンも参照URLが残るため、過去のチャットボットでも引き続き動作します。

## 現在の対応範囲

プロトタイプとして「1.3. FAX振り分け」章のみ画像を配置済み。

## 注意

- 現在は公開リポジトリでテスト用に使用中
- 本番運用時は非公開ストレージへ移行予定
